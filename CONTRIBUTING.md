# Contributing to GeoFlow

Thank you for your interest in contributing to GeoFlow!

Please refer to our comprehensive **[Contributor & Developer Guide](docs/contributing.md)** for:
- Technical Architecture & Subpackage Map
- Development Environment Setup (`pip install -e ".[all]"`)
- Engineering Patterns (`_clone()` subclass propagation, CRS contract, etc.)
- Running Test Suites (`pytest`)
- Known Codebase Quirks & Audit Findings (High-priority roadmap items)
- Pull Request Guidelines

For the full interactive documentation site:
```bash
pip install mkdocs-material
mkdocs serve
```
